# Historical development records

These plans, numbered reports and earlier test instructions document how the
system was developed. They describe the source and environment at their recorded
revision and can contain obsolete commands, local paths or incomplete features.
They are not current setup or operating instructions.

Use the [project README](../../../README.md), [setup guide](../../SETUP.md),
[architecture](../../ARCHITECTURE.md), [testing guide](../../TESTING.md) and
[validation status](../../VALIDATION.md) for the current system. Historical commands
remain relative to the repository root at the recorded revision unless stated
otherwise. Local machine paths in these records are provenance, not prerequisites.
